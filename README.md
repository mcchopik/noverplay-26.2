# NoverPlay for Minecraft 26.2

Fabric port of [Jselyx/noverplay-mod](https://github.com/Jselyx/noverplay-mod) for Minecraft 26.2.

The latest build is available from the `Artifacts` archive attached to the newest successful [GitHub Actions run](https://github.com/mcchopik/noverplay-26.2/actions/workflows/build.yml).

## Requirements

- Minecraft 26.2
- Fabric Loader 0.20.1 or newer
- Fabric API
- Java 25
